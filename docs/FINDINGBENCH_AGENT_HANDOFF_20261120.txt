一、研究问题与论文故事

核心主张是解耦高层规划与低层执行，用固定的公共技能接口划定可对照边界。高层只凭自然语言、图像和交互历史选择技能和点位；低层负责点选落地、几何与安全检查、物理执行。两层分别留下证据，便于区分「策略不知道下一步该做什么」和「知道但当前机器人或执行器做不到」。研究贡献是可诊断、可比较的规划与执行分层；稠密布局是要研究的任务范式，RAB 提供可复用资产，不把造数据写成最大创新，也不预设分层一定提高成功率。

任务范式是家庭协作式找物：找、辨认、取出、送达、尽量复原。例：人说“去厨房拿瓶酱油放在餐桌上”。桌上没有目标，机器人去厨房，记住已搜过哪个柜子；必要时移动遮挡，CHECK 区分酱油和醋，拿对物体后放到明确位置，尽量关门、放回挪开的东西。这是研究原型，不宣称 RAB 当前有酱油、车库或所有住宅房型。主任务文本只写自然请求，不提示“用 CHECK”“复位其他物品”“Then report completion.”。REPORT_DONE 是公共技能，可在接口文档中解释。显式安全或复位提醒仅用于诊断对照。导航是必要技能，近距离内多个候选／遮挡是主要难点。任务要求目标及数量实际存在、目的地无歧义、相似物有可见或 CHECK 可验证的判别依据。

论文叙事：
- 真实家庭找物挑战是不完全观测下的视觉识别、推理、记忆、主动观察、复位与物理约束。控制多余移动距离后，仍可因候选分支、遮挡和干扰对象产生难度。
- 定位：早期 Mechanical Search / RAY 有稠密遮挡，不能说它们假定稀疏；它们的局域找物设定与家庭指令下取送、复原、现代高层模型及失败归因是互补的。HSC 可作“密集布局下表征困难”的候选文献，本工作问规划与执行如何分别限制表现。RAB 是复用基础，对比任务、接口和分析目标，不把资产写成自己造的。讨论 π0.5 等 VLA/WAM 时，只针对可核对的具体训练、数据和部署任务，不能笼统写所有模型假定稀疏。前述是查证线索，引用原文前复核。
- 主要科学对照：同任务、起点、执行器、预算及观测，换高层模型或上下文；固定高层策略或冻结决策输入，在配对场景中改变明确定义的低层执行能力或使用受控的参照执行，比较哪些差距会消失。特权可达性检查、知道目标的原语回放只作工程诊断或上限，不是公平的视觉模型 baseline。换低层时固定动作语义、其余条件和版本；单模型低分或事后猜测不证明两层瓶颈的因果关系。
- 数学支撑先读 docs/household_search_formalization.md。等先验、每次完美检查只辨明一个候选、成功须检查取得目标、候选间移动代价固定为零时，检查次数的期望为 (n+1)/2，最坏 n。可引用可分成本下按 q_i/p_i 排序的交换论证。真实动态开门、遮挡和搬动是部分可观测问题，不能套用该闭式最优。理论说明分支可以独立于距离产生复杂度，不证明现有 VLA 必然失败。若需经验结论，做同房间、同目标、同起点与距离匹配的少量疏／密配对，比较已冻结执行器下表现；不为这一额外对照拖延首批 MCP。

三、这一周冻结的 benchmark 合同

1. 三个集合：原始 RAB 1K 库存、预先选定并验收的 pilot、排除／替补账本。提议 pilot 24–36 条，开放遮挡、抽屉、冰箱分层，兼顾单／多目标、短／跨区及不同背景。罕见冰箱可以超额抽样，单列该口径，不把 pilot 当 1K 的总体 SR。预先写固定候选及替补顺序；同室派生对、同家族或同语义模板以组切分，查结构签名、房间、资产、语义重复。先对纳入的 pilot 验公开点选下的找物到送达路径；特权脚本只证明受控原语或可行路径，不算真人数据。阻塞就记录物理／语义依据，按预定规则替换；不能偷偷换目标。暂不扩建房型、增数据或重跑全部 1K，除非发现系统性阻塞。
2. 难度先按同一公共接口的人类参考步数和可完成性分层，记录人、试次、预算、成功数、分箱边界、必要开合／移挡。候选区域数、相似干扰、遮挡层和距离单独记录；不先用它们冒充人类难度。Human oracle 是可达到成本，不是已证明最优；已存在的同协议真人数据可重放，历史 BEHAVIOR 不混入。至少争取一个真人公开闭环；不足标分层 provisional，不把 agent 脚本叫人类或用合成结果填数。
3. SR：指定目标数量全部到明确的目的地、受正确表面或容器支撑、静稳且释放；明确 REPORT_DONE、错误提交与预算末步终止顺序。复位不并入主任务 SR，除非显式诊断任务要求。ST 的 v1 提案是成功试次的完成耗时，另报成功步数和计时边界；若旧 ST 有其他含义，冻结文档用可读列名消歧。分开模型、工具、仿真耗时，报有效试次、成功数、超时、无效基础设施数和重跑数；SR 分母与排除规则预登记，不从成功者耗时推全体效率。主表 SR / ST / 复位，按人类难度或任务族报告样本数及置信区间；小样本只作 pilot，可按布局组 bootstrap 报不确定性。
4. 复位复用 scripts/rab_restore.py 的连续相似度。非目标对象分别计正确承托关系、同容器坐标下位移／姿态误差、门或抽屉的实测位置／转角，聚合到 [0,1]。错支撑／掉落／缺失明确，目标离开原位不扣分；测得的机关状态不能用 drive 指令替代。冻结前用原样、轻微偏移、错格、门未关四种控制核尺度／缺失项。遮挡级联、多物堆叠要核承托识别，不把支持路径换名误计失败。
5. 图 1：不确定度随技能步数下降的曲线。DER-n 只在预定义候选集与先验、可复核的观测排除规则成立时做：H_t = -sum p_t log p_t，DER-n = H_t - H_(t+n)，注明对数底、粒度与未知遮挡。不要用 GT 直接消除不确定性，也不要把自报置信度当标定 posterior。动态候选跟踪不足时，用可验证的剩余候选／排除过程，或把 DER 标 NOT RUN；不是交付阻塞项。
6. 图 2：从 episode 成功／失败开始，区分未找到、错认、错送达／虚假完成、预算、执行阻塞；基础设施单列，复位低分独立。图 2b（原提案图 3）：所有提交动作中实际执行比例；在未执行中分别算不可达、风险／碰撞、动作／状态不适用（旧帧、占手等）、其他／未知。已驱动物理但后置条件失败，与前置拒绝分开；不要以一个公开 UNSAFE 直接推断具体根因。定义允许核对原日志，episode 与 action 分母分别写清。重复失败率本周不加，除非实际行为提示需要且能可靠判断状态和观测无实质变化。
7. 诊断优先固定执行器比较普通指令 vs 显式“别碰掉东西／请复位”，以及短 vs 长历史；每次只改一项、保持公平预算。针孔 vs 全景、是否给深度 GT 单独版本化；带特权深度不混作 baseline。显式技能提醒同样是独立对照。第一周至少冻结对照设计，若余量只试一个，不延误 MCP。旧 BEHAVIOR 全景成绩不能直接作 RAB 针孔的配对控制。

四、怎么把 MCP 接通，什么算完成

实现显式 RAB stdio 入口（如 serve-mcp --backend rab 或独立模块），保留旧路可辨识。优先复用已经实测的 localhost HTTP skill worker；stdio 进程不 import Kit，只管理自己启动的进程并转发，稳定后再考虑 IPC。用清单解析任务 ID，不允许任意路径、文件读取、自由相机或编辑 API。每次 reset 新建 native world，同 ID 重置和换 ID 不继承状态。原生 stdout/stderr 落日志，stdio stdout 只输出 MCP JSON-RPC；启动和请求有超时、readiness、独立 TMPDIR、清理及错误分类。开始串行占一个 GPU worker，不停止别人的进程；基础设施重试有上限且保留失败记录。

工具沿用 reset_episode、observe、act、episode_status：
- reset_episode(task_id) 返回公开初始帧与新的 episode 身份；私有 manifest 固定清单 SHA、场景 SHA、依赖／执行器、horizon、seed 或明确的确定性政策。若 worker 不支持 seed，不默默吞掉也不声称生效。
- observe 不扣步、不推进物理；MCP ImageContent 传原生 PNG，辅以结构化元数据。实测客户端能看到和使用图像，不把 base64 直接当一大段模型文字。CHECK 独立附图，不能成为 scene 点选帧。
- act 直接传给权威执行器，运输层不代替模型改动作、挑坐标或提示。四个公共码：EXECUTED、INVALID_ACTION、OUT_OF_CAPABILITY、UNSAFE。细原因私有，除非专门的已登记反馈对照。每条被系统处理的提交（含过期帧）按冻结口径计一次；未提交、纯传输失败与基础设施失败分开。终止后拒绝后续物理动作并且不扣步；检查并修正当前 worker 的终止边界后再冻结。episode_status 公开运行、完成、失败或超时，不给目标身份、oracle 路径、失败私因和场景真值。工具响应成功与任务成功分开。
- 先假 worker 测错误与进程生命周期，再用标准 MCP client 与真实 Kit 握手：列工具 → reset → observe → VIEW → 点选 CHECK 或 OPEN → 过期帧负控 → 当帧正常动作 → REPORT_DONE 与状态；加同 ID reset、换 ID、终止后拒绝、挂起进程回收、HTTP 与 MCP 的公开字段／帧和 PNG 一致性。覆盖真实正例 F251 抓放、F262 开关、F087 导航。另须实际验证至少一条 RAB 任务的公开找取送达成功轨迹；不能拿技能单测或特权回放代替。日志分离公开输入输出与私有评估，Worker 崩溃不归模型。
- 用同一 MCP 客户端启动真实读图模型首批 baseline。优先已有本机模型或已经授权且有预算的模型，别等额外训练。冻结 checkpoint/endpoint、任务清单、预算、输入图像与上下文、模型重试和评估代码；记录原始动作、公开图像或哈希、工具应答、私有物理诊断、时间、任务终态和排除账本。先小批产出真实轨迹，再派发可恢复队列；“开始评测”的证据是实际模型 episode 落盘、有派发与退出标记，不是只建立空队列或真人示范。若无可用模型或授权，交付已实跑的真实 MCP 和可运行 runner，注明具体阻塞，不冒称模型已开跑。
