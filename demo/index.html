RummageBench

An embodiment-aware diagnostic benchmark for interactive object search: the admissible action space is dynamically grounded from robot capability, object affordance and world state — and execution is perfect by construction.

Framework: the Embodied Action Grounding Engine

Existing embodied benchmarks evaluate agents through end-to-end successful execution, which entangles high-level decision quality with low-level execution noise. RummageBench factors the two apart. Every step, the admissible action space is regenerated:

A skill is not chosen from a fixed list — it emerges from the world. Structured failures (UNREACHABLE, COLLISION, INVALID_STATE) come from the validators themselves, so failure attribution is mechanical, not hand-labeled.
